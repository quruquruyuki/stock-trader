# 株ラボ（stock-trader）

日本株・米国株の売買戦略を **バックテスト** して、良さそうなものを **模擬取引（ペーパートレード）** で走らせるアプリ。
実際の証券口座には一切注文を出さない。

- 画面：GitHub Pages（`index.html` / `app.js`）
- 売買エンジン：`engine.js`（バックテストと模擬取引で同じコードを使う。Edge Function の `engine.js` は、この engine.js を jsDelivr 経由でコミット固定で読み込むだけ。エンジンを変えたら push → そのコミット番号に書きかえて関数をデプロイ）／`research.js`（バックテストの集計と総当たり。画面だけで使う）
- データ・模擬取引：Supabase（「quruquruyuki's Project」に同居。テーブルは `st_` で始まる）
- Edge Function：`stock-trader`（`supabase/functions/stock-trader/`）
- 自動実行：pg_cron で平日 18:10（日本株の引け後）と翌朝 8:10（米国株の引け後）に全ボットを進める

## 売買のルール
- 日足。その日の終値でシグナルを判定し、**翌営業日の始値**で約定（滑り＝スリッページを上乗せ）
- 通常は買い。「売買の向き」を空売りにすると、シグナルで売りから入り、消えたら買い戻す（貸株料を年率で差し引く。逆日歩・売り禁は未考慮）。複数銘柄は資金を銘柄数で等分
- 戦略（31種）：トレンド系（移動平均・EMAクロス、3本の移動平均、MACD、一目均衡表、パラボリックSAR、スーパートレンド、回帰トレンド、モメンタム、テクニカル評価）／ブレイク・出来高系（高値ブレイク、ADXブレイク、ケルトナー、ボラティリティ拡大、インサイドバー、ピボット反転、出来高急増、VWAP、価格帯別出来高）／逆張り（RSI、ストキャスティクス［ファスト・スロー］、ボリンジャー、アルティメット・オシレーター、連続下落、フィボナッチ押し目）／パターン（ローソク足19種、チャートパターン8種）／資産の乗り換え（上昇率の高いものを持つ）／月末・月初、恐怖指数2種、買い持ち＋損切り・利確・トレンド条件
- 相場フィルター（市況）：条件を複数組み合わせられる（最大8つ）。株（指数が上向き・下向き、恐怖指数、調整局面、高値圏、ハイテク株・小型株が強い、信用不安）／金利（利上げ・利下げ局面、長期金利の上昇・低下）／景気・物価（逆イールド、失業率の上昇、インフレ懸念）／為替・原油（円安・円高、原油高・原油安）／金・債券／季節（5〜10月、11〜4月）。条件ごとに「売買を控える」「この時だけ売買する」を選び、どれか1つでも売買しない側に当てはまる日を「弱気」として、新規買い停止・全部売る・半分で買うのどれかに切り替える。ボットごとに「自動／強気で固定／弱気で固定」も選べる
- 指標：VIX（Cboeの公開CSV）、日経平均VI（日経平均プロフィルの公開CSV）、金利・ドル円・原油・期待インフレ率・失業率（FREDの公開CSV）を取り込み、相場フィルターと「市況」タブに使う。個人利用の範囲で使うこと
- 買う量の決め方：資産の割合／金額で固定／株数で固定／損切り幅から逆算（1回の負けを資産の◯%に抑える）。売買単位は自由に入力できる
- ボットの比較：2つ以上あると、模擬取引タブに損益を重ねたグラフと表が出る
- 週末のまとめ：毎週土曜8:30に、各ボットの今週の損益と恐怖指数の水準を通知（Edge Function `stock-weekly`）
- 総当たり：期間を前半7割・後半3割に分け、前半で選んだ数値が後半でも通用するかを見る
- 通知：模擬取引の約定・翌営業日の注文・安全装置での停止を Web Push で知らせる（鍵は自動生成して st_config に保存）
- Notion：バックテスト結果を「Claude連携」データベースに保存（NOTION_API_KEY を共用）
- 安全装置（模擬取引）：1日の取引回数上限、1日の損失で停止、最高値からの下落で停止、全ボット停止ボタン

## 株価データ（初回だけ設定）
Supabase → Edge Functions → Secrets に登録する。
- `JQUANTS_API_KEY`：J-Quants（JPX公式）のAPIキー。無料プランは過去2年・12週間遅れ。最新の株価で模擬取引するならライトプラン以上
- `TIINGO_API_KEY`：Tiingo のAPIトークン（米国株、無料プランで可）
- `ALLOWED_EMAIL`：他のアプリと共用（設定済み）

## 税金・レバレッジ・比べる相手
- 口座：特定口座（利益の20.315%を手じまいごとに引き、同じ年の損失と相殺。買い持ちも最後の日に売った前提で課税して比べる）／NISA（非課税）／税金を考えない
- レバレッジ：1.5〜3倍。毎日、元の値動きの◯倍で動くETFを想定して計算する（売買の判断は元の値動き）。模擬取引では、読み込む期間が変わっても値段がずれないように前回の値段にそろえる
- 比べる相手：指数（米国株は SPY、日本株は 1306）を持ち続けた場合か、入れた銘柄を持ち続けた場合
- 自動探索：買って持ち続ける＋各フィルター、主な戦略の長めの設定、弱気の日の動き（持ち株も売る／新規だけ止める）も試す。並べ方は「指数並み・下落半分」（年率が指数の9割以上で最大下落が半分以下）など6種類
- 市況タブ：S&P500（SPY）と日経平均（FREDの日次終値。1営業日遅れ・高値安値なし）のテクニカル評価をメーターで表示（日足・週足）。計算は戦略「テクニカル評価」と同じ（移動平均15本＋オシレーター11個）
