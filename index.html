細かい設定

空売りは、シグナルが出たら売りで入り、消えたら買い戻します。相場フィルターを使うと「弱気のときだけ仕掛ける」になります。逆日歩や売り禁などは計算に入っていません。

終値でシグナルを判定し、翌営業日の始値で約定する前提です。「滑り」は約定値が不利にずれる分の見込みです。複数銘柄のときは資金を銘柄数で等分します。

パラメータを総当たりで比べる

いろいろな数値の組み合わせを一気に試します。期間を前半（7割）と後半（3割）に分け、前半で成績の良かった組み合わせが、後半でも通用するかを確かめます。前半だけ良いものは「過去に合わせすぎ」の可能性が高いです。

取引の一覧

過去の成績は将来の成績を約束しません。模擬取引で、これから先のデータでも通用するか確かめましょう。

仮想のお金で売買します。実際の証券口座には一切注文を出しません。毎営業日の引け後に自動で更新されます。

株価データの接続

確認中…

日本株：J-Quants（JPX公式）

  1. J-Quants（jpx-jquants.com）でユーザー登録し、プランを選ぶ（無料プランから可）
  2. ダッシュボードの「設定 → APIキー」でAPIキーを発行
  3. Supabase → Edge Functions → Secrets に JQUANTS_API_KEY として登録

無料プランは過去2年分・12週間遅れのデータです。バックテストは無料で試せます。模擬取引を「今日の株価」で回すにはライトプラン（月1,650円）以上が必要です（無料プランでも12週間遅れで模擬取引は進みます）。

米国株：Tiingo

  1. Tiingo（tiingo.com）で無料アカウントを作る
  2. アカウント設定の「API → Token」でトークンをコピー
  3. Supabase → Edge Functions → Secrets に TIINGO_API_KEY として登録

無料プランで長期の日足データが取れます（個人利用）。
